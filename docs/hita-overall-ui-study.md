## 采用与保留的设计
借鉴的是标题/头卡/胶囊/轨道/课程行/空状态的组件组合，以及统一材质、间距和导航层级。实现仍为本应用的原生Java组件，不移植HITA的业务或主题引擎，不加入资讯/助手/社交等无关入口。

| 页面 | 0.4的整体变化 |
|---|---|
| 页面骨架 | 顶部小字品牌日期、主标题、圆角管理入口、统一浅色画布 |
| 今日头卡 | 白色主表面，左侧课程名、右侧状态胶囊，圆形进度和次级信息独立分层；保留用户先前确认的圆形进度，而非照搬HITA的线性指示 |
| 时间轴 | 低亮的最近已结束项、连续轨道节点、白色描边课程卡、时间信息胶囊、可选地点与教师信息 |
| 导航 | 统一白色圆角容器及选中胶囊，移除默认Android按钮视觉 |
| 周课表 | 圆角白色画板、今天的日期胶囊、课程颜色边标、跨节次块，保留一屏七天 |
| 周次选择/管理 | 底部面板统一拖拽指示、标题、内容区；周次为四列选择网格 |
| 登录 | 大标题与说明、白色表单卡、填充式输入框、主色提交按钮、次级已有登录入口；小屏键盘场景可滚动 |
| 未导入 | 主副文案和主操作组织成独立空状态卡 |

不同课程颜色和缺失地点留空继续保留。完整像素、玻璃模糊和主题切换不是本轮实现范围，也不声称是HITA某主题的原样复刻。
