# 课间 · Kejian

课间是一款 Android 课表与备忘录应用。它能导入本学期的课表，显示今天的课程、上课进度和下一门课。已保存的课表和备忘可以离线查看。

## 下载与更新

需要 **Android 10 或以上版本**。在 [GitHub Releases](https://github.com/TuYun0906/Kejian/releases/latest) 下载最新版 APK。已安装的用户可以在「更多 → 关于·更新」手动检查，也可以在启动时接收更新提示。应用最多每天自动检查一次，发现新版后可打开浏览器下载。

若无法访问 GitHub 或无法获取更新信息，请加入 QQ 群获取最新版本。

## 主要功能

- **课表导入**：正式版支持潍坊学院和安徽理工大学。打开右上角菜单，选择学校并点「登录 / 更新课表」，即可获取当前学期课表。也可以新建空白课表，手动添加课程。
- **今日**：显示课程时间、教室、教师，以及距开课、恢复上课或下课的时间。已结束、正在进行和即将开始的课程有不同样式。按住进度圆环上下拖动可预览百分比，松手后回到实时进度。
- **一周课表**：左右滑动或选择教学周，点击课程查看详情。长按课表可查看学期和本地保存时间。在「课表管理」可以保存、切换、删除本地课表，也可以导入或导出课表文件。
- **提醒与通知**：支持课前提醒和可自定义的上课状态通知。长按「课程提醒」可修改提前提醒的分钟数。提醒的准时性取决于设备的通知和提醒权限。
- **备忘**：支持文字、清单、图片和手绘。可搜索、按标签等条件筛选、置顶、归档和从回收站恢复。长按卡片可进入编辑选项或拖动排序。
- **百宝箱**：提供可拖动、可贴边的悬浮倒计时和毫秒秒表。倒计时结束时会显示静音顶部横幅，可点击或上滑关闭。使用悬浮窗需要系统的「显示在其他应用上层」权限。
- **个性化**：支持浅色、深色及跟随系统，可选择预设主题色或自定义 RGB。导航栏支持调整位置、顺序和显示项目。点击头像可编辑昵称、选择并裁剪头像。

## 从源码构建

需要 JDK 17 和 Android SDK Platform 35。项目使用 Gradle Wrapper 8.9 和 Android Gradle Plugin 8.7.3。

用 Android Studio 打开仓库根目录并同步 Gradle，或在已配置 Android SDK 的终端运行：

```powershell
.\gradlew.bat :app:assembleDebug
```

macOS / Linux 可运行 `sh ./gradlew :app:assembleDebug`。生成文件位于 `app/build/outputs/apk/debug/app-debug.apk`。覆盖安装需要相同的应用 ID 和签名证书。本机构建的调试签名可能与已分发 APK 不同。

## 配置应用内更新

1. 将 `app/src/main/assets/update-repository.txt` 设为公开仓库的 `OWNER/REPO`。
2. 发布新版本时，更新 `app/build.gradle` 中的 `versionName`，递增 `versionCode`，并使用同一签名证书构建 APK。
3. 在 GitHub Releases 创建正式版本，使用类似 `v0.8.25` 的标签，并上传同版本的 APK，例如 `kejian-0.8.25.apk`。Release 正文会显示为应用内更新说明。

## 测试

